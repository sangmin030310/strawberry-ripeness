# 앵커 · 딸기 과실 탐지 및 성숙 단계 식별

- **프로그램** · 전주대학교 RISE 특성화 인재양성 프로그램
- **팀 구성** · 4인
- **개발 환경 및 기술(계획)** · YOLO 기반 객체 탐지, 이미지·영상 데이터 라벨링
- **목표** · 사진과 영상에서 딸기 과실의 위치를 찾고, 미숙·착색 중·완숙으로 구분해 화면에 표시하는 시제품 개발

## 왜 이 프로젝트를 시작했나

수업에서 배운 객체 탐지를 실제 딸기 재배 영상에 적용해 보고 싶었습니다. 딸기는 조명에 따라 색이 다르게 보이고, 잎에 가려 과실의 일부만 보일 때도 있습니다. 저희 팀은 이런 장면에서도 딸기를 찾아 익은 정도를 구분할 수 있을지 알아보고자 이 주제를 선택했습니다.

직접 영상을 모아 과실의 위치와 성숙 단계를 표시하고, 그 데이터로 모델을 학습시킬 계획입니다. 학습 결과를 바탕으로 어떤 장면에서 딸기를 놓치거나 익은 정도를 잘못 판단하는지 확인하는 것까지가 이번 프로젝트의 목표입니다.
