# 앵커 · 딸기 과실 탐지 및 성숙 단계 식별

## 왜 이 프로젝트를 시작했나

수업에서 배운 객체 탐지를 실제 재배 영상에 적용해 보고 싶었습니다. 딸기는 촬영할 때 조명에 따라 색이 다르게 보이고, 잎에 가려 과실의 일부만 보이는 경우도 있습니다. 그래서 저희 팀은 이런 조건에서도 영상 속 딸기를 찾아 **미숙·착색 중·완숙**으로 구분할 수 있을지 알아보고자 했습니다.

전주대학교 RISE 특성화 인재양성 프로그램에서 이 주제를 선택했습니다. 직접 영상을 모으고 과실의 위치와 성숙 단계를 표시한 뒤, 모델이 어떤 장면에서 딸기를 놓치거나 성숙 단계를 잘못 판단하는지 살펴보는 것이 프로젝트의 목표입니다.
